About RtDt.

A Javascript implementation of a Raytracer, for Node.js and WebView. Designed and implemented by Dave. Intended as a reference implementation for porting to native C, as a modeller.

Raytracer · Node.js · WebView
Import file

Repository samples are hosted with RtDt on GitHub Pages; no local download is needed.

For animated scenes, load the scene before its .phy file. JSON .scene is supported in the browser; YAML scene loading is not yet supported.
