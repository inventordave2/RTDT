# Historical CLI folder

The supported Node CLI is **root** [cli.js](../cli.js), run from the repo root using `node cli.js --help`. This subfolder's `cli-bootstrap.js` / `cli.js` are legacy code with earlier global-state assumptions, not supported production entrypoints.

The current root CLI renders built-in scenes to P3 PPM. JSON `.scene` input, `--config`, `--batch`, `--output-dir` and PNG/JPEG/BMP CLI export are not connected.

See [current CLI guide](../CLI_README.md) and [archived historical CLI documents](../docs/archive/rtdt-development-docs/README.md).
