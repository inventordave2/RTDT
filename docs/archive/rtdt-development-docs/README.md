# RtDt historical development documents — archived

**Archived on 19 November 2026.** This is the former `refactoring-plan/` directory plus superseded completion reports and old quick-start guides. These files are preserved for provenance, not as current instructions.

**Do not use the commands or completion claims in this archive as authoritative.** They describe older experiments and proposals involving `raytracer.html`, `cli-bootstrap.js`, `Data`/`DataR`, unsupported `--scene-file` YAML execution, and misleading assertions of 100% completion. Some source examples are intentionally retained verbatim as historical references.
