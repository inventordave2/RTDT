# RtDt standalone OBJ library

This folder stores standalone meshes distributed with RTDT, including the cat, teapot, teddy and pyramid. It is not a private user account collection.

Packaged `samples/*.scene` examples place private dependencies under a corresponding scene-name folder, or reusable pack dependencies under `samples/shared/`. Scene asset paths must be relative to the scene file (not `../obj/`). See [scene-pack creation](../SCENE_PACK_CREATION.md).
