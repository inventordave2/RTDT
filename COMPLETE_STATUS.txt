================================================================================
DESIGN DECISIONS
================================================================================

1. UNIVERSAL JAVASCRIPT (Not ES6 Modules)
   WHY: Works in browser without build tools, works in Node.js trivially
   HOW: Global functions, eval() in Node.js, <script> tags in browser

2. SHARED raytracer-core.js
   WHY: Same rendering logic, guaranteed identical output
   HOW: Platform-agnostic functions (no DOM/canvas/fs calls)

3. SEPARATE Platform Code
   WHY: Clean separation of concerns, easier maintenance
   HOW: raytracer-ui.js (browser) vs rtdt_objfile-node.js + cli.js (Node.js)

4. NO BUILD TOOLS
   WHY: Maximum portability, zero configuration, trivial deployment
   HOW: Direct file serving (browser), direct execution (Node.js)

5. PPM OUTPUT FORMAT
   WHY: Universal (works everywhere), lossless, human-readable
   HOW: P3 text format, easily convertible to PNG/JPEG with ImageMagick

USAGE EXAMPLES

BROWSER EXAMPLES:

From HTML button:
  <button onclick="mySkyBox(); renderImage();">Render Sky</button>

From JavaScript console:
  > mySkyBox()         // Load scene
  > renderImage()      // Render to canvas

CLI EXAMPLES:

Render scene1 at 150x84:
  node cli-bootstrap.js --scene scene1 --width 150 --height 84 --output output.ppm

Render with custom quality:
  node cli-bootstrap.js --scene mySkyBox --width 300 --height 169 --quality 4 --output sky.ppm

Show all options:
  node cli-bootstrap.js --help

Convert PPM to PNG:
  convert output.ppm output.png
